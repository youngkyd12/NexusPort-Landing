# NexusPort Landing Page

Trang giới thiệu chính thức cho hệ sinh thái **NexusPort - Hệ thống Quản lý & Điều phối Cảng Biển Thông Minh (Tiên Sa, Đà Nẵng)**.

## 🌟 Tính Năng Nổi Bật
- **Full-Screen Video Background:** Video cảng biển `port.mp4` tự động phát mượt mà, tối ưu hiệu năng.
- **Glassmorphic Navigation Header:** Thiết kế kính mờ cao cấp, hiển thị trạng thái `Tiên Sa Live`.
- **Hero Content Bottom-Left:** Định vị thông tin chuẩn UX Pro Max với dải đo lường KPI thực tế.
- **Bento Grid 6 Phân Hệ:** Giới thiệu trực quan Smart Gate, Cẩu RTG, Booking e-EIR, Driver App, Shipping Line và Reefer Telemetry.
- **7 Tác Nhân Phối Hợp:** Chuẩn hóa quy trình vận hành đa bên của cảng.
- **Quy Trình Thông Xe Khép Kín:** 5 bước khép kín từ đặt lịch đến xuất cổng.

## 🚀 Khởi Chạy Dự Án
```bash
# Cài đặt thư viện
npm install

# Khởi chạy server phát triển (Port 3000)
npm run dev

# Đóng gói sản xuất
npm run build
```

## 🔗 Liên Kết Ứng Dụng Chính
Mặc định kết nối tới NexusPort UI tại `http://localhost:5173`. Có thể cấu hình qua biến môi trường:
```env
VITE_NEXUSPORT_APP_URL=http://localhost:5173
```
